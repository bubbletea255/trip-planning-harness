# 여행 조건 수집 체크리스트 (Intake Questionnaire)

Intake Agent가 이 파일을 기준으로 사용자 입력의 완성도를 판단한다.
필수 항목이 모두 채워져야 다음 단계로 넘어갈 수 있다.

---

## 필수 항목 (모두 수집해야 함)

| 항목 | 확인 질문 | 허용 형태 |
|---|---|---|
| 목적지 | 어디로 가실 예정인가요? | 도시명, 국가명, 지역명 |
| 여행 기간 | 며칠 일정인가요? (또는 출발일과 귀국일) | "3박 4일", "5월 10-14일" |
| 예산 총액 | 총 여행 예산이 얼마인가요? | 금액 + 통화 ("150만원", "$1,500") |
| 인원 및 구성 | 몇 명이 가시나요? 구성이 어떻게 되나요? | "혼자", "커플", "가족 3인(아이 1)" |
| 주요 관심사 | 여행에서 가장 중요한 것이 무엇인가요? | "맛집", "자연", "문화유적", "쇼핑", "휴양" 등 |

---

## 선택 항목 (있으면 더 정확한 계획 가능)

| 항목 | 확인 질문 | 기본값 (미제공 시) |
|---|---|---|
| 출발지 | 어디서 출발하시나요? | 한국(서울) 기준 |
| 숙박 선호도 | 선호하는 숙박 형태가 있나요? | 중급 호텔 |
| 이동 수단 선호도 | 대중교통을 선호하나요, 렌터카를 선호하나요? | 대중교통 |
| 일정 강도 | 여유롭게 돌아보고 싶으신가요, 많이 보고 싶으신가요? | 보통 |
| 특별 요청 | 식단 제한, 접근성 요구사항, 꼭 가고 싶은 곳이 있나요? | 없음 |

---

## 수집 규칙

1. 이미 제공된 항목은 다시 묻지 않는다.
2. 한 번에 최대 3개 항목만 질문한다.
3. 필수 항목이 모두 채워지면 선택 항목을 한꺼번에 물어볼 수 있다.
4. 사용자가 선택 항목을 건너뛰면 기본값을 적용하고 "가정한 사항"에 명시한다.
5. 목적지가 여러 곳(예: "도쿄와 오사카")이면 각각을 별도 목적지로 처리한다.

---

## 애매한 입력 처리

| 입력 예시 | 처리 방법 |
|---|---|
| "유럽 어딘가" | 국가 또는 도시를 좁혀달라고 요청 |
| "여름에" | 구체적인 월 또는 주를 확인 |
| "넉넉하게" | 금액 범위를 확인 |
| "친구들이랑" | 몇 명인지 확인 |
