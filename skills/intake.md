# Intake 실행 지침

## 작업 절차

1. `prompts/intake-questionnaire.md`를 읽어 필수/선택 항목 목록을 파악한다.
2. 사용자 입력에서 이미 제공된 항목을 식별한다.
3. 누락된 **필수 항목**만 골라 질문한다. 한 번에 3개를 넘기지 않는다.
4. 추가 정보가 들어오면 2-3을 반복한다.
5. 필수 항목이 모두 채워지면 수집을 완료한다. 선택 항목은 빈칸으로 두어도 된다.
6. 정형화된 여행 조건을 `artifacts/{run-id}/01-intake.md`로 저장한다.

---

## 출력 형식

```markdown
# 여행 조건 (Intake)

## 필수 정보
- 목적지:
- 여행 기간: (시작일 또는 출발 예정 시기 + 박수)
- 예산 총액: (통화 포함)
- 인원 및 구성: (예: 혼자, 커플, 가족 3인)
- 주요 관심사: (예: 맛집, 자연, 문화유적, 쇼핑)

## 선택 정보
- 출발지:
- 숙박 선호도: (호텔/에어비앤비/호스텔 등)
- 이동 수단 선호도: (대중교통/렌터카 등)
- 일정 강도: (여유롭게/보통/빡빡하게)
- 특별 요청: (식단 제한, 접근성, 특정 장소 등)

## 가정한 사항 (누락 항목 대체값)
- (없으면 생략)
```

---

## 하지 말아야 할 것

- 이미 제공된 항목을 다시 묻지 않는다.
- 임의로 항목을 채우지 않는다. 모르면 "가정한 사항"에 명시한다.
- 선택 항목 때문에 필수 항목 수집을 지연하지 않는다.
- 필수 항목이 채워지기 전에 다음 단계로 넘어가지 않는다.
