# 조사 결과 (Research)

## 목적지 개요
- 최적 방문 시기 / 현재 시기 적합도: 5월은 맑고 선선한 날씨로 도보 관광에 최적. 단 주말은 주요 관광지 혼잡.
- 특이사항: 경복궁 야간 개장(사전 예약 필수), 광장시장·통인시장은 현금 결제 선호.

## 교통
- 공항 → 숙소: 해당 없음 (서울 내 출발로 가정)
- 시내 이동: 지하철·버스 T-money 카드 기준 1회 1,400원 (10km 이내 기본)
- 이동 시간 참고표:
  | 구간 | 이동 수단 | 소요 시간 |
  |---|---|---|
  | 경복궁 ↔ 광장시장 | 버스 또는 도보 | 25분 (버스) / 35분 (도보) |
  | 광장시장 ↔ 인사동 | 도보 | 10분 |
  | 인사동 ↔ 을지로 | 지하철 2호선 | 10분 |
  | 을지로 ↔ 성수동 | 지하철 2호선 | 15분 |
  | 경복궁 ↔ 북촌 한옥마을 | 도보 | 15분 |

## 조사 주의사항
- 광장시장·을지로 노가리 골목은 현금 결제 비율이 높음 → 소액 현금 준비 권장
- 경복궁 화요일 휴관 → 대안: 창덕궁(3,000원, 월 휴무 없음)으로 대체 가능
- 성수동 인기 식당은 점심 오픈 전 대기 발생 → 11:30 이전 방문 권장
- 숙박 가격은 성수기·예약 시점에 따라 변동 가능 (2024년 기준)
