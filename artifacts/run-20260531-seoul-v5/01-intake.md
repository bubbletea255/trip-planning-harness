# 여행 조건 (Intake)

## 필수 정보
- 목적지: 서울 (대한민국)
- 여행 기간: 1박 2일
- 예산 총액: 300,000원 (1인)
- 인원 및 구성: 혼자 (1명)
- 주요 관심사: 맛집, 문화유적

## 선택 정보
- 출발지: 서울 내 또는 수도권 (당일 이동 기준)
- 숙박 선호도: 게스트하우스 또는 저가 호텔
- 이동 수단 선호도: 대중교통 (지하철·버스)
- 일정 강도: 보통
- 특별 요청: 없음

## 가정한 사항 (누락 항목 대체값)
- 출발지 미제공 → 서울 내 출발로 가정 (별도 교통비 산정 없음)
- 숙박 선호도 미제공 → 예산 고려하여 게스트하우스 기본값 적용
