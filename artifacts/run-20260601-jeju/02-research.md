## 목적지 개요

- 최적 방문 시기 / 현재 시기 적합도: 6월은 제주도 성수기 초반으로 기온 22~27°C, 습도 상승 전 쾌적한 편. 다만 주말은 인기 관광지와 맛집 대기가 길어질 수 있어 평일 방문 권장.
- 특이사항:
  - 27개월 아기는 36개월 미만으로, 여러 관광지에서 무료 입장 또는 무료 이용 혜택 적용.
  - 6세 미만 아동은 도로교통법상 카시트 착용 의무 (위반 시 운전자 과태료 6만 원).
  - 해물라면 맛집 일부는 재료 소진 시 조기 마감하므로 오전~점심 일찍 방문 필요.
  - 렌터카 카시트는 수량 한정이므로 예약 시 반드시 사전 요청.

- 인천 → 제주 편도: 60,000~130,000원/인

## 조사 주의사항

1. **가격 변동 가능성:** 렌터카, 숙박 요금은 시즌·예약 시점에 따라 큰 폭으로 변동. 실시간 비교 플랫폼에서 날짜 입력 후 최종 확인 필수.
2. **쪼꼴락상회 조기 마감:** 재료 소진 시 영업 종료. 오전 11시 이전 방문 또는 오픈 직후 방문 강력 권장.
3. **카시트 예약:** 제주도 렌터카 업체 카시트 수량 한정. 차량 예약 시 동시 요청 필수.
4. **아쿠아플라넷 36개월 미만 무료 증빙:** 의료보험증, 주민등록등본 등 직계가족 확인 서류 지참 필요.
5. **에코랜드 vs 아쿠아플라넷:** 1박 2일 일정상 두 곳 모두 방문 시 이동 시간 과부하. 하나만 선택 권장 (아기 동반 시 에코랜드가 이동 거리·체력 소모 면에서 유리).
6. **항공권 아기 요금:** 국내선 무릎 탑승 시 요금 항공사별 정책 상이. 예약 전 각 항공사 공식 확인 필수.
7. **숙박 최대 인원 확인:** 한림리조트 등 일부 리조트는 최대 인원 초과 입실 불가. 아기 포함 3인 기준 입실 가능 여부 예약 전 문의 필수.
8. **예약 확인 필요 항목:** 아쿠아플라넷 운영 시간, 중문해물라면오빠네 정확한 가격, 각 숙소 유아 추가 요금 정책.
