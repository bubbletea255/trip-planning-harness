# 여행 조건 (Intake)

## 필수 정보
- 목적지: 제주도
- 여행 기간: 1박 2일 (출발일 미정)
- 예산 총액: 1,000,000원
- 인원 및 구성: 성인 2명 (나 + 아내) + 27개월 아기 1명
- 주요 관심사: 아기와 함께할 수 있는 일정, 해물라면 맛집 (반드시 포함)

## 선택 정보
- 출발지: 한국(서울) 기준 가정
- 숙박 선호도: 미제공 → 가족실 또는 중급 호텔/펜션 가정
- 이동 수단 선호도: 미제공 → 렌터카 가정 (아기 동반 가족 여행 특성상)
- 일정 강도: 미제공 → 여유롭게 (아기 동반)
- 특별 요청: 해물라면 맛집 반드시 포함, 아기 동반 가능 장소 우선

## 가정한 사항 (누락 항목 대체값)
- 출발지: 서울 기준 (항공편 포함 예산 계산)
- 숙박: 가족실 가능한 중급 호텔 또는 펜션
- 이동 수단: 렌터카 (아기 카시트 포함) — 아기 동반 시 대중교통보다 렌터카가 유리
- 일정 강도: 여유롭게 — 아기 낮잠 시간 및 수유 시간 고려
