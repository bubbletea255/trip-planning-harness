# 여행 일정 (Itinerary)

## 전체 요약
- 목적지 / 기간 / 인원: 서울 / 1박 2일 / 성인 2명 + 27개월 아기
- 일정 강도: 여유롭게 (27개월 아기 동반)
- 특이사항:
  - 오후 13:00~15:00 아기 낮잠 시간 고려하여 오전 집중 관람, 오후 휴식 패턴 유지
  - 첫날 저녁은 서울 현충원(동작구) 근처에서 작은아빠 합류 외식 — 택시 이동 권장
  - 동작역 유모차 환승 복잡 → 저녁 이동 전 구간 택시 사용
  - 호텔 추천: 호텔 나루 서울 엠갤러리 (마포, 48개월 미만 조식 무료)
  - 총 예상 지출: 약 258,000~360,000원 (예산 500,000원 이내 여유롭게 가능)
  - 서울상상나라 사전 온라인 예약 필수 (최소 1~2일 전)

## 대안 일정

- **비 오는 날**:
  - 1일차 오전: 서울상상나라는 실내 시설이므로 우천 무관하게 정상 진행 가능.
  - 2일차 오전: 국립중앙박물관 어린이박물관 역시 실내 — 동일하게 진행.
  - 추가 대안: 동작구 소재 서울형 키즈카페 (대방동·상도동) — 아동 2,000~5,000원, 회차제 운영, 우리동네키움포털 예약. 저녁 식사 전 여유 시간에 활용 가능.

- **아기 컨디션 나쁜 날 (칭얼거림, 열기 등)**:
  - 1일차: 서울상상나라 체험 시간을 1시간으로 단축 → 점심 후 바로 호텔 체크인 → 낮잠 충분히 확보. 저녁 외식 대신 호텔 근처 배달 또는 테이크아웃으로 전환 가능.
  - 2일차: 국립중앙박물관 일정 취소 → 호텔 주변 공원 또는 홍대 인근 산책으로 대체 → 일찍 귀가. 아기 컨디션 최우선.
  - 전반적: 일정 전체를 하루 앞당겨 1일차 관광 취소하고 서울 도착 후 바로 호텔 체크인, 2일차 오전 한 곳만 방문하는 미니 코스로 재구성 가능.

- **서울상상나라 예약 실패 시 (매진, 월요일 등)**:
  - 서울어린이대공원 (동일 역 위치)으로 대체. 공원 무료 입장, 야외 동물원 관람 (10:00~17:00). 유모차 대여 3,000원. 맑은 날 잔디 피크닉 가능.
  - 국립민속박물관 어린이박물관 (경복궁역) 으로 대체 가능 — 사전예약 필수, 무료.
