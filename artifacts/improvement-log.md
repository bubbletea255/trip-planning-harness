# 개선 기록 (Improvement Log)

하네스 실행 후 발견된 문제, 사용자 피드백, 개선 내용을 기록한다.
이 기록을 바탕으로 `agents/`, `skills/` 파일을 개선한다.

---

## 기록 형식

```markdown
## YYYY-MM-DD | {run-id} | {개선 유형}

**발견된 문제**: 
**원인**: 
**적용한 개선**: 
**변경된 파일**: 
```

---

## 개선 유형 분류

| 유형 | 설명 |
|---|---|
| Agent 지시 부족 | Agent가 예상과 다른 결과를 냈을 때 |
| 루브릭 조정 | Judge 채점 기준이 현실과 맞지 않을 때 |
| 플로우 수정 | Phase 순서나 의존 관계 변경 |
| 산출물 형식 | 출력 파일 형식 개선 |
| 오류 처리 | 예외 상황 대응 추가 |
