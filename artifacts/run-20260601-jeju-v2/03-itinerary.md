## 대안 일정

- **쪼꼴락상회 대기 또는 재료 소진 시**: 애월의 노라바를 대안으로 검토한다. 다만 운영시간과 대기 방식은 방문 당일 재확인한다.
- **우천 시**: 협재해수욕장 또는 한담 산책을 줄이고 아쿠아플라넷 제주로 대체할 수 있다. 단, 서부권 숙소에서 성산까지 이동이 길어 공항 출발 시간이 늦은 날에만 권장한다.
- **아기 컨디션 저하 시**: 2일차 에코랜드를 생략하고 한담 산책 + 공항 근처 이호테우해변/카페로 단축한다.
- **도착 항공편 지연 시**: 이호테우해변을 생략하고 공항 → 쪼꼴락상회 → 숙소 체크인으로 바로 진행한다.
