# 조사 결과 (Research)

- run-id: run-20260601-jeju-v2
- 조사 기준일: 2026-06-01
- 대상: 제주도 1박 2일 / 성인 2명 + 27개월 아기 1명 / 예산 1,000,000원 / 렌터카 이동

---

## 목적지 개요

- 최적 방문 시기 / 현재 시기 적합도: 6월 제주도는 야외 산책과 해변 놀이가 가능한 시기다. 다만 성수기 초입이라 항공권·숙박·렌터카 가격 변동이 커서 날짜 확정 후 실시간 예약 확인이 필요하다.
- 특이사항:
  - 27개월 아기 동반 일정이므로 하루 이동 시간을 짧게 잡고, 낮잠 시간을 숙소 또는 차량 이동 시간에 배치한다.
  - 제주 렌터카는 보험 조건, 셔틀, 카시트, 취소 규정을 함께 비교해야 한다.
  - 해물라면 필수 조건은 협재의 `쪼꼴락상회`를 1순위로 반영한다.
  - 쪼꼴락상회는 다이닝코드 기준 09:00~19:00, 라스트오더 18:00, 해물라면 13,000원, 문어해물라면 16,000원으로 확인했다.
  - 한담해안산책로는 비짓제주 기준 애월항에서 곽지과물해변까지 이어지는 총 1.2km 해안 산책로다.

## 교통

- 서울 → 제주 항공: KAYAK 조회 페이지 기준 서울-제주 저가 항공권은 34,603원부터 노출된다. 실제 날짜·시간·수하물·좌석 조건에 따라 성인 1인 편도 40,000~100,000원 이상까지 변동 가능.
- 렌터카: 카모아는 제주 렌터카 업체별 실시간 예약 가능 차량, 요금, 보험 조건, 셔틀 여부를 비교할 수 있다고 안내한다. 아기 동반은 준중형/SUV와 카시트 옵션 확인을 권장한다.
- 추천 이동 방식: 제주공항 렌터카 인수 → 서부권(협재/한림) 숙박 → 2일차 애월/에코랜드 → 공항 반납.
- 카시트: 렌터카 예약 시 사전 요청 필수. 수량 제한 가능.

## 조사 주의사항

- 항공권, 숙박, 렌터카 가격은 날짜 확정 전까지 변동 폭이 크다.
- 쪼꼴락상회는 가격과 영업시간을 다이닝코드에서 확인했지만, 재료 소진·임시휴무 가능성이 있어 방문 당일 재확인 권장.
- 에코랜드 요금과 영유아 무료 기준은 방문 전 공식 채널에서 최종 확인 필요.
- 아쿠아플라넷은 우천 대안으로 좋지만 서부권 숙박 기준 이동 시간이 길다.
- 숙박비는 객실 단가 기준으로 산정한다. 기준 인원 초과 요금, 영유아 포함 가능 여부는 예약 전 확인해야 한다.
