## 대안 일정

### 우천 시 대안
- 1일차 어린이대공원 산책 → **숙소 근처 실내 카페 또는 키즈카페** 로 대체
- 2일차 박물관 정원 → 생략 후 국립중앙박물관 본관(상설전시, 실내) 관람으로 대체

### 서울상상나라 예약 마감 시 대안
- 서울상상나라 → **키즈오케이 인증 실내 체험관** (놀이의숲, 뮤지엄그라운드 등 어린이대공원 인근) 으로 대체
- 또는 일정 순서 변경: 1일차 국립중앙박물관, 2일차 서울상상나라

### 아기 컨디션 난조 시 대안
- 모든 야외 이동 최소화, 숙소에서 휴식 후 부분 재개
- 어린이박물관 1회차 예약 시 2회차(12:00) 로 늦춰서 아기 오전 낮잠 확보

## 핵심 예약 체크리스트
1. **숙소** — 체크인 전 짐 보관 가능 여부 확인, 아기의자 또는 온돌룸 요청
2. **서울상상나라** — 방문 며칠 전 홈페이지 예약 (주말이라면 최소 1주일 전)
3. **국립중앙박물관 어린이박물관** — **방문 14일 전 00시** 온라인 예약 오픈. 이 일정 중 가장 선행되어야 할 예약
4. **담양에초대 룸** — 저녁 식사 최소 3~4일 전 전화 예약, "아기의자 필요·유아 동반" 명시
