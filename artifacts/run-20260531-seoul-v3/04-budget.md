# 예산 분석 (Budget)

## 예산 요약
- 입력 예산: 500,000원 / 인원: 성인 2명 + 27개월 아기 (3인)
- 추정 총액: **428,800원**
- 차이: **-71,200원 여유**
- 예비비 (10%): 42,880원 포함

## 예산 검토

추정 총액(예비비 포함) 513,480원이 입력 예산 500,000원을 약 13,480원(2.7%) 초과한다.
예비비를 포함하지 않으면 470,600원으로 29,400원 여유가 있다.

**실질적 권고**: 예비비는 사용하지 않는 것이 최선이므로 아래 절감 방안 중 하나를 선택하면 예비비 포함 예산 내 유지가 가능하다.

## 절감 방안 (초과 시)

### 방안 1: 숙소를 이비스 앰배서더 동작으로 변경 (절감 약 80,000~100,000원)
- 220,000원 → 120,000원 내외로 교체
- 현충원 저녁 식사 후 귀환 거리도 단축
- 단점: 2일차 이촌역(박물관) 이동 시 지하철 4호선 직통이지만 좌석 여유 없을 수 있음

### 방안 2: 1일차 점심을 어린이대공원 내 간이식당·푸드트럭으로 간소화 (절감 약 10,000원)
- 3인 30,000원 → 20,000원 이내로 조정
- 아기 밥은 지참하거나 간단히 해결
- 단점: 식사 선택지 제한

## 주의사항
- 담양에초대 저녁식사 금액은 작은아빠 지분 포함(4인). 작은아빠가 별도 부담하면 이 항목을 3인 약 66,000원으로 재산정 가능 → 전체 약 22,000원 추가 절감
- 택시 요금은 시간대·교통 상황에 따라 최대 20% 변동 가능
- 서울상상나라 입장료: 36개월 미만 아기 무료 증빙 서류(가족관계증명서 등) 현장 지참 필요 여부 사전 확인
