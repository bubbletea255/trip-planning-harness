# 여행 조건 파일 형식 (Intake Output Schema)

`artifacts/{run-id}/01-intake.md`가 따라야 할 출력 형식.

---

```markdown
# 여행 조건 (Intake)

## 필수 정보
- 목적지:
- 여행 기간: (시작일 또는 출발 예정 시기 + 박수)
- 예산 총액: (통화 포함)
- 인원 및 구성: (예: 혼자, 커플, 가족 3인)
- 주요 관심사: (예: 맛집, 자연, 문화유적, 쇼핑)

## 선택 정보
- 출발지:
- 숙박 선호도: (호텔/에어비앤비/호스텔 등)
- 이동 수단 선호도: (대중교통/렌터카 등)
- 일정 강도: (여유롭게/보통/빡빡하게)
- 특별 요청: (식단 제한, 접근성, 특정 장소 등)

## 가정한 사항 (누락 항목 대체값)
- (없으면 생략)
```
