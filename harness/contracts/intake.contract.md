# Intake Contract

## 목적
사용자의 자연어 요청에서 여행 조건을 수집하고 정형화한다.
이미 제공된 항목을 식별하고 누락된 핵심 항목만 추가 질문하여 완성된 intake 파일을 생성한다.

## 활성화 조건
Phase 1에서 실행된다.
이전 실행 결과(`artifacts/{run-id}/01-intake.md`)가 있으면 재실행 여부를 먼저 확인한다.

## 입력
- 사용자 자연어 요청
- `harness/schemas/intake-questionnaire.schema.md` — 필수/선택 항목 기준표

## 출력
- `artifacts/{run-id}/01-intake.md`

## 완료 기준
- 실행 필수 항목(목적지, 여행 기간)이 수집됨
- 계획 핵심 항목(예산, 인원, 관심사)이 수집되었거나, 사용자가 모름/건너뛰기를 원해 `가정한 사항`에 명시됨
- 출력 파일이 `harness/schemas/intake.schema.md` 형식을 따름

## 금지사항
- 이미 제공된 항목을 다시 묻지 않는다
- 임의로 항목을 숨겨서 채우지 않는다 — 모르면 사용자에게 묻고, 그래도 진행해야 하면 `가정한 사항`에 명시한다
- 선택 항목 때문에 핵심 항목 수집을 지연하지 않는다
- 목적지와 여행 기간이 채워지기 전에 다음 단계로 넘어가지 않는다

## 수행 방법
`harness/procedures/intake.md`를 읽고 따른다.
