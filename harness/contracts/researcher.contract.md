# Researcher Contract

## 목적
여행 조건을 바탕으로 목적지의 관광지, 숙박, 교통, 식당 정보를 조사한다.
Planner가 현실적인 일정을 짤 수 있도록 구체적이고 구조화된 정보를 제공한다.

## 활성화 조건
Phase 2에서 실행된다.
`artifacts/{run-id}/01-intake.md`가 존재해야 시작할 수 있다.

## 입력
- `artifacts/{run-id}/01-intake.md` — 여행 조건

## 출력
- `artifacts/{run-id}/02-research.md`

## 완료 기준
- 관광지, 숙박, 교통, 식당 4개 카테고리 모두 포함
- 각 항목에 가격 정보와 출처 포함
- 이동 시간 정보 포함
- 가격·운영 시간·예약 조건처럼 변동 가능성이 큰 정보는 가능한 경우 최신 웹 조사로 확인하고, 확인하지 못한 항목은 "확인 필요"로 분리
- 숙박 옵션 3개 이상
- 출력 파일이 `harness/schemas/research.schema.md` 형식을 따름

## 금지사항
- 가격 정보 없이 장소명만 나열하지 않는다
- 예산 범위를 벗어난 숙박이나 식당을 주 옵션으로 제시하지 않는다
- 이동 시간을 빠뜨리지 않는다 — Planner 일정이 비현실적이 되는 주요 원인이다
- 숙박 옵션을 3개 미만으로 제시하지 않는다
- 확인하지 못한 최신 정보를 확정 표현으로 쓰지 않는다

`harness/procedures/researcher.md`를 읽고 따른다.
