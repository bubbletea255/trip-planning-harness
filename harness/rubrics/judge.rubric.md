# Judge 루브릭 (Judge Rubric)

Judge 절차가 두 플랫폼 결과를 채점할 때 사용하는 기준표.
모든 항목은 1-5점 척도이며, 가중치를 적용해 100점 만점으로 환산한다.

---

## 평가 항목

### 1. 일정 완결성 (25점)
요청한 여행 일수 대비 실제로 계획된 비율을 평가한다.

| 점수 | 기준 |
|---|---|
| 5 | 요청 일수 100% 계획됨 + 대안 일정 포함 |
| 4 | 요청 일수 100% 계획됨 |
| 3 | 80% 이상 계획됨 |
| 2 | 60% 이상 계획됨 |
| 1 | 60% 미만 |

### 2. 예산 준수 (25점)
추정 총액이 입력 예산(예비비 포함) 대비 얼마나 벗어났는지 평가한다.

| 점수 | 기준 |
|---|---|
| 5 | 예산 이내 (초과 없음) |
| 4 | 5% 이하 초과 |
| 3 | 10% 이하 초과 |
| 2 | 20% 이하 초과 |
| 1 | 20% 초과 또는 예산 미포함 |

### 3. 이동 현실성 (20점)
하루 이동 시간 합계가 현실적인지 평가한다. 이동시간 = 교통수단 탑승 시간 기준.

| 점수 | 기준 |
|---|---|
| 5 | 모든 날 이동 4시간 이하 |
| 4 | 평균 이동 4-6시간 |
| 3 | 평균 이동 6-8시간 |
| 2 | 평균 이동 8-10시간 |
| 1 | 10시간 초과 또는 이동시간 미명시 |

### 4. 카테고리 커버리지 (15점)
숙박, 교통, 식사, 관광 4개 카테고리가 모두 포함됐는지 평가한다.

| 점수 | 기준 |
|---|---|
| 5 | 4개 카테고리 모두 포함 + 각 카테고리에 구체적 정보 |
| 4 | 4개 카테고리 포함 (일부 정보 빈약) |
| 3 | 3개 카테고리 포함 |
| 2 | 2개 카테고리 포함 |
| 1 | 1개 이하 |

### 5. 대안 제시 (15점)
예비 선택지가 포함됐는지 평가한다. (날씨 대비, 예약 불가 시 대안 등)

| 점수 | 기준 |
|---|---|
| 5 | 주요 항목마다 대안 포함 |
| 4 | 일정 또는 숙박 중 하나에 대안 포함 |
| 3 | 대안 일정 1개 이상 포함 |
| 2 | 대안 언급은 있으나 구체성 낮음 |
| 1 | 대안 없음 |

---

## 총점 계산

```
총점 = (일정 완결성 점수 × 5) + (예산 준수 점수 × 5) + (이동 현실성 점수 × 4) + (카테고리 커버리지 점수 × 3) + (대안 제시 점수 × 3)
최대 = 25 + 25 + 20 + 15 + 15 = 100점
```

---

## 권고 기준

| 상황 | 권고 방식 |
|---|---|
| 총점 차이 10점 이상 | 높은 점수 안을 권고, 이유 명시 |
| 총점 차이 5-9점 | 높은 점수 안을 권고, 낮은 점수 안의 강점도 언급 |
| 총점 차이 5점 미만 | 항목별 강점 비교 후 조건부 권고 ("예산 우선이라면 A, 일정 유연성이 중요하면 B") |
| 하이브리드 가능 | 부분 채택 제안 (예: "A안 일정 + B안 숙박 선택") |

---

## 채점 원칙

- 루브릭 외 주관적 선호로 점수를 조정하지 않는다.
- 각 항목 채점 시 근거를 한 줄 이상 명시한다.
- 정보가 부족해 판단할 수 없는 항목은 1점으로 처리하고 이유를 명시한다.
