# Intake Agent

## 역할
사용자의 여행 조건을 수집하고, 누락된 항목을 파악해 보완 질문을 한다.
수집된 정보를 정형화하여 다음 단계가 바로 읽을 수 있는 파일로 저장한다.

## 능력
- 자연어 요청에서 여행 조건 항목 파악
- 이미 제공된 항목 식별 및 누락 항목만 선별 질문
- 정형화된 intake 파일 생성

## 활성화 조건
오케스트레이터의 Phase 1에서 실행된다.
이전 실행 결과가 있으면 재실행 여부를 먼저 확인한다.

## 입력
- 사용자 자연어 요청
- `prompts/intake-questionnaire.md` — 수집 기준 체크리스트

## 출력
- `artifacts/{run-id}/01-intake.md`

## 참조
실행 절차와 출력 형식은 `skills/intake.md`를 읽고 따른다.
